# System Design

Allocation Engine 2.0 is isolated from the original Allocation Manager
implementation.

The research engine contains:
- Deterministic scenario generation.
- Five allocation policies.
- Capacity-constrained assignment.
- Worker availability scenarios.
- Multi-dimensional metric computation.
- Checkpointed experiment execution.
- Paired scenario analysis.
- CSV and JSON result exports.
- Data-derived figures.

The original src/ implementation is preserved.
