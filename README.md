# Allocation Manager AI

Multi-agent warehouse allocation system with centralized optimization and real-time task distribution.

---

## Core System

- Worker agents perform autonomous navigation
- Allocation Hub assigns tasks using distance-based optimization
- Items are classified and routed to target zones
- Metrics engine evaluates throughput and efficiency

---

## Key Features

- Priority-aware task allocation
- Scalable multi-agent coordination
- Real-time simulation environment
- Experiment-driven evaluation pipeline

---

## Experiment Modes

- NORMAL
- STRESS_TEST
- FAILURE_CONDITIONS
- SCALABILITY
- EXTREME_LOAD

---

## Output

- Throughput metrics
- Task completion rate
- System stability under load
